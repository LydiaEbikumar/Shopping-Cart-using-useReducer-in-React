
# Shopping Cart using useReducer in React

This project is a simple shopping cart application built with React. It demonstrates how to use the `useReducer` hook for managing cart state such as adding, removing, and updating item quantities.

---


### Usage

First install the dependencies

```bash
npm install
```

Then run the application

```bash
npm start
```

Once it’s running, open your browser

```bash
http://localhost:3000
```

---

### Folder Structure

```bash
/src
  /components
    Cart.js
    ProductList.js
  App.js
  index.js
```

---

### Cleanup

To stop the server

```bash
Ctrl + C
```

To remove installed packages

```bash
rm -rf node_modules
```
